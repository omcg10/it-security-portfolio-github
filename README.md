# IT Security Portfolio – Server Hardening & Vulnerability Assessment

This repository showcases a hands-on IT security assessment focused on real-world system administration,
network scanning, service hardening, and troubleshooting.

It is designed as an **IT / Cybersecurity portfolio project** demonstrating practical skills rather than theory.

## Skills Demonstrated
- Linux system administration
- Network scanning & service enumeration
- Identifying insecure configurations
- Service hardening & verification
- Troubleshooting and validation
- Documentation for technical and non-technical audiences

## Environment
- Target OS: Linux (EOL kernel)
- Target IP: 192.168.107.129
- Environment: Virtualized (VMware)
- Role: Junior IT / Security Analyst

## Tools Used
- Nmap
- Telnet client
- Linux system services
